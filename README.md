# Data-Analysis-Portfolio

Hello, I'm Oliver! This repository showcases my work and projects as I pursue opportunities in data analytics. With a background in financial analysis and experience working with large datasets, I focus on turning raw data into actionable insights that drive decision-making.

This portfolio highlights my skills in:

1) Data cleaning and transformation (SQL, Python, Pandas)
2) Exploratory data analysis and visualization (Matplotlib, Tableau)
3) Building dashboards and reporting solutions
4) Applying analytical thinking to real-world business problems

Each project in this repository reflects a hands-on approach to solving problems across different domains, including finance, operations, and consumer data. My goal is to demonstrate not just technical ability, but also the ability to communicate insights clearly and effectively.

I’m actively seeking data analyst opportunities where I can contribute to data-driven decision-making and continue growing my analytical skill set.

## Projects

### [Retail Profitability Leakage: The True Cost of Heavy Discounting](https://github.com/owhu/The-True-Cost-of-Heavy-Discounting)
Tools: Tableau, Python, SQL, Pandas, Matplotlib, Seaborn 

A case study investigating the financial impact of discounting strategies on profit margins. This project translates raw transaction data into insights by pairing SQL and Python with an interactive, narrative-driven Tableau dashboard.

### [Patient No-Show Prediction](https://github.com/owhu/Patient-No-Show-Prediction/blob/main/Patient%20No-Show%20Prediction.ipynb)
Tools: Python, Pandas, Matplotlib

Analyzed 100K + medical records (Python, Pandas, Matplotlib ) to identify drivers of patient no-shows
Identified lead time as the strongest predictor of cancellations, informing scheduling optimization strategies
